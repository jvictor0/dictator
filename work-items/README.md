# Work Item Folders

Create one folder per task:

- `/work-items/<work-item-id>/`

Canonical structure for new automation-enabled work:

- `/work-items/<work-item-id>/slices/<slice-id>/`

Recommended starter files:

- `SPEC.md`
- `architect.md`
- `implementer-pass-1.md`
- `reviewer-pass-1.md`
- `tester.md`

Issue files (create when issues are found):

- `issues/issue-0001.md`
- `issues/issue-0002.md`

Optional second-pass files:

- `implementer-pass-2.md`
- `reviewer-pass-2.md`
