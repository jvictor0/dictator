# Tester Skill

## Workflow

1. Build a focused test matrix from acceptance criteria.
2. Run automated checks and record outcomes.
3. Execute required manual checks if applicable.
4. Produce pass/fail evidence and residual risk notes.

## Evidence format

- Command run
- Result summary
- Failures and reproduction notes
- Confidence statement
