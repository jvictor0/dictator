# Architect Skill

## Workflow

1. Clarify goal, scope, constraints, and success criteria.
2. Identify impacted contracts, modules, and risks.
3. Produce a decision-complete plan with file-level impact.
4. Define acceptance criteria and testing requirements.

## Output checklist

- Scope and non-goals
- Interface changes and compatibility notes
- Edge cases and failure handling
- Test plan
- Handoff package for implementer
